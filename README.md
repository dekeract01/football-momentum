# Football Momentum

Can a computer see momentum? This project measures football momentum using [StatsBomb's open data](https://github.com/statsbomb/open-data) from the 2022 World Cup, and tests whether it's anything more than chance.

Read the full write-up on my [blog](https://dekeract01.github.io/blog/football-momentum), or run `football_momentum.ipynb` to make all the figures.
